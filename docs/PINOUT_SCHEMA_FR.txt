2. DIAGRAMME DE CÂBLAGE - AFFICHAGE TFT ILI9341
================================================================================

TFT ILI9341 (connecteur SPI 7 broches) :
─────────────────────────────────────────

  Vue de face du connecteur TFT :

  [VCC] [GND] [CS]  [RST] [DC] [MOSI] [SCK] [MISO] [BL]
    5V   GND  GPIO5  GPIO46 GPIO6 GPIO11 GPIO13 GPIO12 GPIO12

  Diagramme détaillé :

  TFT Pin     │ Nom     │ ESP32 GPIO │ Description
  ────────────┼─────────┼────────────┼──────────────────────────────────
  1 (rouge)   │ VCC     │ 5V         │ Alimentation (via MT3608 5V stable)
  2 (noir)    │ GND     │ GND        │ Masse
  3           │ CS      │ GPIO 5     │ Chip Select (SPI bus)
  4           │ RST     │ GPIO 46    │ Reset (actif bas)
  5           │ DC      │ GPIO 6     │ Data/Command (0=cmd, 1=data)
  6 (jaune)   │ MOSI    │ GPIO 11    │ Master Out Slave In (SPI data)
  7           │ SCK     │ GPIO 13    │ Serial Clock (SPI clock)
  8 (vert)    │ MISO    │ GPIO 12    │ Master In Slave Out (SPI)
  9 (bleu)    │ BL      │ GPIO 12    │ Backlight (via transistor)

Circuit MT3608 (réglage 5V) :
  1. Mesurer VOut avec multimètre → doit être 5.0V exactement
  2. Potentiomètre petit (vis jaune) sur le module
  3. Tourner lentement jusqu'à 5.0V
  4. ⚠️ NE PAS DÉPASSER 5.1V (risque endommager TFT)

Formule lecture tension batterie :
  Vbatt = (ADC_value / 4095) * 3.3V * ((100 + 47) / 47)
  Vbatt = (ADC_value / 4095) * 3.3V * 3.13

Calibration :
  • Batterie 3.7V = ADC value ~1570
  • Batterie 4.2V = ADC value ~1795

  ┌────────┐

11. RÉSUMÉ CONNECTEURS & CONNECTIVITÉ
================================================================================

[SPI Partagé - 3 périphériques]
  • TFT ILI9341 (SPI+GPIO) → Affichage
  • NRF24L01+ (SPI) → Scan 2.4GHz
  • CC1101 (SPI) → Scan 433MHz

[I2C Bus - 2 périphériques]
  • DS3231 (I2C) → RTC
  • SSD1306 (I2C optionnel) → Affichage OLED fallback

[UART - 2 connexions]
  • UART0 → Serial monitor Debug (via adaptateur USB)
  • UART1 → GPS NEO-6M

[GPIO Entrées]
  • 4 boutons tactiles
  • 1 mesure batterie ADC

[GPIO Sorties]
  • 1 backlight TFT
  • 1 buzzer piézo

[Alimentation]
  • TP4056 (charge batterie LiPo via USB-C)
  • MT3608 (boost 3.7V → 5.0V stable)
  • Interrupteur principal

================================================================================
12. CHECKLIST PRÉ-ASSEMBLAGE
================================================================================

Avant de commencer le câblage :

  [ ] Tous les composants disponibles
  [ ] Multimètre en bon état
  [ ] Pinces, peigne connecteur, fils striés prêts
  [ ] Workspace propre et bien éclairé
  [ ] Batterie chargée (ou power bank 3.3V)
  [ ] Respirateur/ventilation si soudage


Ordre de câblage recommandé :
  1. Alimentation (GND commun d'abord)
  2. TFT (affichage prioritaire)
  3. Boutons (tests rapides)
  4. Batterie ADC (monitoring)
  5. I2C bus (RTC + OLED)
  6. Modules RF (NRF24 + CC1101)
  7. GPS (optionnel)
  8. Buzzer/LED (cosmétique)


Tests après chaque étape :
  • Inspirer les connexions (court-circuit?)
  • Vérifier continuité au multimètre
  • Tester avec l'ESP32 allumée (LED check)

  │  UART                                                   │
  │  • ROUGE      = TX (out)                                │
  │  • BLEU CIEL  = RX (in)                                 │
  └─────────────────────────────────────────────────────────┘


================================================================================
14. POINTS CRITIQUES À VÉRIFIER
================================================================================

⚠️ AVANT DE BRANCHER LA BATTERIE :

  1. MULTIMÈTRE CHECK
     [ ] GND et VCC bien séparés (pas de court-circuit)
     [ ] MT3608 output = 5.0V exactement (± 0.1V)
     [ ] Pas de continuité entre VCC et GND

  2. CONDENSATEURS
     [ ] 10µF NRF24 en place et bien soudé
     [ ] 100nF CC1101 en place et bien soudé
     [ ] Rien n'y manque sinon = crash/instabilité

  3. SPI BUS
     [ ] CS pins bien séparés (GPIO 5, 10, 14)
     [ ] Pas de mélange MOSI/MISO
     [ ] SCK bien connecté partout

  4. I2C BUS
     [ ] Pull-up 10kΩ présents (TRÈS IMPORTANT)
     [ ] Pas de court-circuit SDA-SCL
     [ ] Adresses I2C correctes (0x68 RTC, 0x3C OLED)

  5. BOUTONS
     [ ] Tous connectés à GND
     [ ] Pas inversés (GPIO au bouton, pas batterie)

  6. BATTERIE
     [ ] Connecteur JST correct (non inversé)
     [ ] Polarité respectée (+/-)
