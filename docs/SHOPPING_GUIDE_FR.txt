================================================================================
6. INSTALLER VS CODE & PLATFORMIO
================================================================================

Étape 6.1 : Télécharger VS Code
─────────────────────────────────
1. Aller sur : https://code.visualstudio.com
2. Télécharger la version pour votre OS (Windows/Mac/Linux)
3. Installer et lancer VS Code


Étape 6.2 : Installer PlatformIO
─────────────────────────────────
1. Dans VS Code, cliquer sur "Extensions" (Ctrl+Shift+X)
2. Rechercher : "PlatformIO IDE"
3. Cliquer "Install" (premier résultat)
4. Attendre la fin de l'installation (~2 minutes)
5. Recharger VS Code (Ctrl+Shift+P → "Reload")
6. Une nouvelle icône "PlatformIO" apparaît dans la barre latérale ✓


Étape 6.3 : Installer Git
──────────────────────────
1. Aller sur : https://git-scm.com
2. Télécharger et installer
3. Redémarrer votre ordinateur après installation


================================================================================
7. CLONER LE DÉPÔT (RÉCUPÉRER LE CODE)
================================================================================

Option A : Avec Git (Recommandé)
─────────────────────────────────

Ouvrir un terminal/invite de commande :
  • Windows : Touche Windows → taper "cmd" → Entrée
  • Mac/Linux : Ctrl+Alt+T ou terminal via menu

Puis exécuter ces commandes :

  git clone https://github.com/mathiscastel29560-arch/Esp32.git
  cd Esp32
  git checkout claude/handshake-wpa2-eapol-capture-r6yp2u

Explication :
  • Ligne 1 : Télécharge le dépôt complet (~200 MB)
  • Ligne 2 : Entre dans le dossier créé
  • Ligne 3 : Bascule sur la branche correcte (dernière version working)


Option B : Sans Git (Download ZIP)
───────────────────────────────────

Si Git non disponible :
1. Aller sur : https://github.com/mathiscastel29560-arch/Esp32
2. Cliquer le bouton vert "Code"
3. Cliquer "Download ZIP"
4. Extraire le ZIP dans un dossier (ex: C:\Users\Votre\Esp32)
5. ⚠️ Vous devez ensuite basculer manuellement sur la bonne branche


================================================================================
8. OUVRIR LE PROJET DANS PLATFORMIO
================================================================================

Étape 8.1 : Ouvrir le dossier
──────────────────────────────
1. Dans VS Code : File → Open Folder (Ctrl+K Ctrl+O)
2. Naviguer et sélectionner le dossier "Esp32" que vous venez de cloner
3. Cliquer "Select Folder"


Étape 8.2 : Attendre la détection
──────────────────────────────────
VS Code détecte automatiquement qu'c'est un projet PlatformIO :
  • La barre de statut en bas affiche : "PlatformIO | env:esp32-s3-audit"
  • Les fichiers de configuration sont reconnus
  • Les dépendances commencent à télécharger automatiquement

⏳ Cela peut prendre 2-5 minutes la première fois (dépendances, libraries)


Étape 8.3 : Vérifier la configuration
──────────────────────────────────────
1. Ouvrir le fichier "platformio.ini" à la racine
2. Vérifier la section "[env:esp32-s3-audit]"
3. Confirmer que "board = esp32-s3-devkitc-1"


================================================================================
9. FICHIER CONFIG.H
================================================================================

Le fichier "include/config.h" contient tous les pins et configurations.

⚠️ Ne pas modifier sauf si :
  • Vous changez le brochage matériel
  • Vous utilisez une carte différente (ESP32 classique, ESP32-C3, etc.)
  • Vous changez le modèle d'affichage

Pins principaux (déjà configurés) :

Composant           | Pins                  | Ligne config.h
────────────────────┼───────────────────────┼────────────────────
TFT SPI             | GPIO 5,6,7,11,12,13   | #define TFT_CS 5
I2C (RTC/OLED)      | GPIO 8,9              | #define I2C_SDA 8
Boutons             | GPIO 1,2,6,42         | #define PIN_BTN_UP 1
Batterie ADC        | GPIO 7                | #define ADC_BATT 7
GPS UART1           | GPIO 17,18            | Serial1.begin(9600)

⚠️ IMPORTANT : Si vous utilisez une ESP32-S3 DIFFÉRENTE (ESP32, ESP32-C3, etc.),
les pins changeront complètement. Consulter la datasheet de votre carte.

11. COMPILER LE FIRMWARE
================================================================================

Étape 11.1 : Vérifier la compilation
─────────────────────────────────────

Dans VS Code :
  1. Cliquer sur l'icône "PlatformIO" (éclair) à gauche
  2. Développer "esp32-s3-audit"
  3. Cliquer "Build"

Ou en ligne de commande :
  pio run

Sortie attendue :
  ✅ [SUCCESS] Took 90 seconds
  RAM: [===       ] 25.1% (82,396 / 327,680 bytes)
  Flash: [======  ] 61.9% (1,947,285 / 3,145,728 bytes)

❌ Si compilation échoue :
  • Vérifier que PlatformIO est bien installé
  • Supprimer le dossier ".pio" et réessayer
  • Vérifier connexion Internet (téléchargement dépendances)
  • Consulter les erreurs : elles indiquent fichier/ligne du problème


================================================================================
12. FLASHER LE FIRMWARE DANS L'ESP32
================================================================================

Étape 12.1 : Préparer le matériel
──────────────────────────────────

Connecter l'adaptateur USB Série à l'ESP32 :
(Voir le fichier guide câblage pour les pins)
  • Adaptateur GND → ESP32 GND
  • Adaptateur RX (in) → ESP32 GPIO 3 (TX)
  • Adaptateur TX (out) → ESP32 GPIO 1 (RX)
  • NE PAS connecter 5V - utiliser batterie ou 3.3V uniquement


Étape 12.2 : Brancher l'USB
────────────────────────────
1. Brancher l'adaptateur USB Série à votre ordinateur
2. Ouvrir le Gestionnaire des périphériques (Windows) ou lsusb (Linux)
3. Noter le port COM (ex: COM3 sur Windows, /dev/ttyUSB0 sur Linux)


Étape 12.3 : Mettre l'ESP32 en mode bootloader
─────────────────────────────────────────────────
1. Maintenir GPIO 0 appuyé vers GND
2. Appuyer sur RESET (ou couper/reconnecter l'alimentation)
3. Relâcher le bouton GPIO 0
4. L'ESP32 passe en mode bootloader (prêt pour flash)


Étape 12.4 : Uploader le firmware
──────────────────────────────────

Dans VS Code :
  1. Cliquer PlatformIO → "Upload" (sous esp32-s3-audit)
  2. Attendre le message de succès (~20-30 secondes)

Ou en ligne de commande :
  pio run -t upload

Sortie attendue :
  ✅ Connecting...
  ✅ Erasing flash...
  ✅ Writing at 0x00000000... (10%)
  ✅ Verifying...
  Hard resetting via RTS pin...


Étape 12.5 : Vérifier le démarrage
───────────────────────────────────

Ouvrir le moniteur série :
  1. PlatformIO → "Device Monitor"
  2. Vérifier le baud rate : 115200

Vous devriez voir :
  ========== SYSTEM DIAGNOSTICS START ==========
  [✓] RTC (DS3231): OK
  [✓] GPS (NEO-6M): OK (UART1 ready for polling)
  [✓] Display (TFT ILI9341): OK (320x240 color)
  [✓] NRF24L01+ (2.4GHz): OK (CONFIG 0x0E)
  [✓] Battery Monitor (ADC): OK (reading 87%)
  ========== SYSTEM DIAGNOSTICS END ==========

💡 Composants affichant MISSING : c'est normal s'ils ne sont pas câblés.
Les composants optionnels (RTC, GPS, CC1101, NRF24) peuvent manquer.
Seul l'affichage est obligatoire.

13. VALIDER LE SETUP
================================================================================

✅ Checklist à faire sur la carte physique :

  [ ] L'écran TFT s'allume (affiche le menu)
  [ ] Les boutons UP/DOWN/SELECT/BACK fonctionnent
  [ ] La batterie charge via TP4056 (LED indicatrice)
  [ ] Le MT3608 sort 5V stable (mesurer au multimètre)
  [ ] Les modules RF (NRF24, CC1101) répondent dans les diagnostiques
  [ ] Le GPS indique prêt pour polling (message serial)
  [ ] Le RTC maintient l'heure

14. RÉSOUDRE LES PROBLÈMES COURANTS
================================================================================

Problème                       | Cause                          | Solution
───────────────────────────────┼────────────────────────────────┼──────────────────────────────
L'écran est noir               | TFT non câblé ou mauvais pins  | Vérifier 7 pins du TFT
Compilation échoue             | Dépendances manquantes         | Supprimer .pio, relancer Build
Upload échoue "Port not found" | Adaptateur USB non détecté     | Essayer autre port, réinstaller
ESP32 redémarre aléatoirement  | Tension instable (MT3608)      | Mesurer MT3608 = exactement 5.0V
NRF24 diagnostic "MISSING"     | Condensateur 10µF manquant     | Ajouter 10µF très proche du VCC
Batterie ne charge pas         | TP4056 non connecté ou USB     | Vérifier câble, LED TP4056

15. COMMENT MODIFIER LE CODE
================================================================================

Le projet est organisé comme ceci :

  Esp32/
  ├── src/
  │   ├── main.cpp (Point d'entrée)
  │   ├── menu.cpp (Système de menu)
  │   ├── wifi_tools.cpp (Outils WiFi)
  │   ├── ble_tools.cpp (Outils BLE)
  │   └── ... (autres tools)
  ├── include/
  │   ├── config.h (Configuration pins)
  │   ├── iot_device_hunter.h
  │   ├── ui/ (Interface utilisateur)
  │   └── ... (headers)
  ├── docs/
  │   ├── FIRMWARE_RELEASE_NOTES.md
  │   └── BUILD_AND_VALIDATION.md
  └── platformio.ini (Config PlatformIO)

Pour ajouter une nouvelle fonction :
  1. Créer un nouveau fichier "src/my_tool.cpp"
  2. Créer un header "include/my_tool.h"
  3. Ajouter include dans "src/main.cpp"
  4. Recompiler : PlatformIO → Build
  5. Uploader : PlatformIO → Upload
