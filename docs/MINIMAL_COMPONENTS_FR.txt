╔════════════════════════════════════════════════════════════════════════════╗
║  COMPOSANTS CRITIQUES (SANS ÇA = PROJECT NE MARCHE PAS)                   ║

✅ ABSOLUMENT OBLIGATOIRE :
───────────────────────────

1. ESP32-S3-N16R8 DevKitC-1
   Pas d'alternative possible

2. TFT ILI9341 320x240 couleur
   Ou : OLED SSD1306 128x64 en mode dégradé (moins beau)

3. Batterie LiPo 1S 3.7V 1000mAh
   Ou : Power bank USB 3.3V (mode test rapide)

4. TP4056 USB-C
   Pour charger la batterie

5. MT3608 Boost converter
   ⚠️ CRITIQUE - C'est ce qui fournit les 5V au TFT et modules RF
   Pas de ça = TFT noir + modules RF morts

6. Adaptateur USB Série (CP2102 ou PL2303)
   Pour flasher le firmware (bootloader)


╔════════════════════════════════════════════════════════════════════════════╗
║  COMPOSANTS IMPORTANTS (FORTEMENT RECOMMANDÉ)                             ║
╚════════════════════════════════════════════════════════════════════════════╝

⚠️ À AVOIR SI POSSIBLE :
────────────────────────

• NRF24L01+ 2.4GHz
  + Condensateur 10µF très proche du VCC (CRITIQUE si utiliser NRF24)
  Fonction : Scan réseaux 2.4GHz (WiFi, Bluetooth, etc.)

• CC1101 433MHz
  + Condensateur 100nF très proche du VCC
  Fonction : Scan bande 433MHz (RF haute puissance)

• RTC DS3231 I2C
  + Résistances pull-up 10kΩ (2x) sur SDA/SCL
  Fonction : Maintenir l'heure

• GPS NEO-6M
  Fonction : Localisation GPS


╔════════════════════════════════════════════════════════════════════════════╗
║  COMPOSANTS OPTIONNELS (PEUT FONCTIONNER SANS)                            ║
╚════════════════════════════════════════════════════════════════════════════╝

❌ PEUT SAUTER :
──────────────

• OLED SSD1306 (si tu as TFT)
  Utilité : Fallback affichage. Pas nécessaire si TFT marche.

• Buzzer piézo
  Utilité : Son lors des scans. Nice-to-have.

• Boutons tactiles (optionnel mais recommandé)
  Sans ça : Uniquement touchscreen/USB
  Avec ça : Navigation physique fluide


╔════════════════════════════════════════════════════════════════════════════╗
║  PASSIFS & CONNECTIQUES - CE QUI EST VRAIMENT CRITIQUE                    ║
╚════════════════════════════════════════════════════════════════════════════╝

RÉSISTANCES :
─────────────

✅ OBLIGATOIRE :
• 10kΩ pull-up I2C (2x) - SINON RTC/OLED ne répondront pas
  Alternative : Peut mettre 4.7kΩ ou 12kΩ aussi

❌ OPTIONNEL :
• 100kΩ + 47kΩ diviseur tension batterie
  Alternative : Lire directement ADC sans diviseur (moins précis)
• 10kΩ base transistor (pour buzzer)
  Alternative : Buzzer directement sur GPIO (mode dégradé)


CONDENSATEURS :
───────────────

✅ CRITIQUES :
• 10µF céramique près NRF24 VCC (si utiliser NRF24)
  Sinon : NRF24 reset random/reboot ESP32
• 100nF céramique près CC1101 VCC (si utiliser CC1101)
  Sinon : CC1101 instable

❌ OPTIONNEL :
• Autres 100nF "découplage"
  Fonction : Stabilité supplémentaire (nice-to-have)


CONNECTEURS & CÂBLAGE :
──────────────────────

✅ OBLIGATOIRE :
• Connecteur JST-PH 2-pin pour batterie
  (Dépend du type de batterie - adapter au connecteur)
• Fils pour câbler
• Connecteurs Dupont (ou soudage)

❌ OPTIONNEL :
• Gaine thermique
  Fonction : Isolation cosmétique
• Multimètre numérique
  Fonction : Calibration MT3608 à 5.0V exactement

================================================================================
COMPOSANTS À NE PAS SKIPER
================================================================================

⚠️ SI TU LES OUBLIES, IL Y AURA DES PROBLÈMES :

1. Condensateur 10µF pour NRF24
   Symptôme : NRF24 diagnostique "MISSING" ou reboot aléatoire
   Solution : Ajouter 10µF très proche du VCC NRF24

2. Condensateur 100nF pour CC1101
   Symptôme : CC1101 instable, reboot
   Solution : Ajouter 100nF très proche du VCC CC1101

3. Résistances pull-up 10kΩ I2C
   Symptôme : RTC/OLED ne répondent pas du tout
   Solution : Ajouter les 2 x 10kΩ sur SDA/SCL

4. MT3608 calibré à 5.0V
   Symptôme : TFT noir, modules RF morts
   Solution : Mesurer MT3608 output au multimètre, régler à 5.0V

SUBSTITUTIONS POSSIBLES
================================================================================

Composant               | Peut être remplacé par           | Notes
────────────────────────┼─────────────────────────────────┼───────────────────
10kΩ pull-up I2C        | 4.7kΩ, 12kΩ                    | Ça marche (I2C flexible)
Résistance diviseur     | Lire ADC brut + formule         | Moins précis, ça marche
Condensateur 10µF       | 4.7µF, 15µF, 22µF              | Tant que c'est µF-scale
Condensateur 100nF      | 47nF, 220nF                    | Tant que c'est nF-scale
NRF24L01+               | NRF24L01+ avec antenne externe  | Meilleure portée
CC1101                  | aucune (unique pour 433MHz)     | PAS DE SUBSTITUTE
RTC DS3231              | DS1307, PCF8563                | Adresses I2C différentes
GPS NEO-6M              | U-Blox NEO-7M, SIM28ML         | Format identique
TFT ILI9341             | ST7789 240x320 identique       | Pin-compatible généralement
Batterie LiPo           | Power bank USB 3.3V            | Mode test (pas rechargeable)
